# UI Localization

Interface language follows the ClawChat/Liveware locale. Do not add a separate
language switch unless the product requirement changes.

Current language families:

- `zh-Hans`: Simplified Chinese.
- `zh-Hant` and `zh_Hant`: Traditional Chinese.
- Other or missing non-Chinese locales: English fallback.

The main interface dictionary lives in runtime `web/i18n.js`; server-produced
localized labels live in runtime code. Preserve interpolation placeholders and
brand anchors exactly. Every locale must contain the full required key set.

Application-code localization changes belong to the updater/engineering
workflow, not ad hoc Skill edits. After an approved release or local engineering
change, restart with `bringup.sh` and verify Simplified Chinese, Traditional
Chinese, and English fallback behavior.
